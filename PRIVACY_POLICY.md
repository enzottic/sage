# Sage Privacy Policy

Last updated: September 4, 2026

Sage does not collect personal information, track users, show advertisements,
or sell data.

## Expense data

Sage stores expenses, budgets, tags, recurring-expense rules, and app settings
on the user's device. Receipt reading uses supported Apple Intelligence features
on the device. Sage does not send receipt images to the developer or to a
third-party service.

If the user turns on iCloud Sync, Sage stores the user's app data in the user's
private iCloud database. Apple operates iCloud and applies its iCloud terms and
privacy policy. The developer does not use this data for advertising, analytics,
or profiling.

## Retention and deletion

Data stays on the device until the user deletes it in Sage, removes the app, or
erases the device. Data stored in iCloud stays there until the user deletes it
through Sage or through the user's iCloud data controls.

Sage includes these deletion controls in Settings:

- Delete Expense Data deletes expenses and can also delete recurring-expense
  rules.
- Delete All Data deletes expenses, recurring-expense rules, tags, and Sage
  settings.

Deletion can sync to iCloud when iCloud Sync is on and the device is connected.
The user can stop future iCloud synchronization by turning off iCloud Sync in
Sage and restarting the app.

## Permissions

Sage asks for camera access only when the user chooses to photograph a receipt.
Sage asks for notification access only when the user turns on recurring-expense
notifications. The user can change these permissions in iOS Settings.
